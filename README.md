⬡ Workspace - Cronômetros & Anotações
Um ambiente centralizado e minimalista projetado para gerenciamento de tempo e organização de notas sem distrações. 

Link: https://workspace-joaquim.onrender.com/

🚀 Funcionalidades:

✅ Gestão de Tempo Personalizada: Criação de cronômetros normais e regressivos com nomes e cores customizáveis para identificar diferentes tarefas.

✅ Anotações Inteligentes: Bloco de notas com suporte a múltiplas notas, cada uma com sua própria identificação visual e salvamento automático.

✅ Organização Dinâmica: Sistema de Drag & Drop que permite reordenar cronômetros e notas conforme a sua prioridade.

✅ Foco Total (Modo Zen): Interface expansível para as notas, ocultando elementos secundários para evitar distrações.

✅ Personalização de Interface: Temas Dark e Light.

✅ Segurança e Backup: Exportação de todos os dados (notas e tempos) para um arquivo TXT, garantindo que você tenha sempre uma cópia local.

🛠️ Tecnologias Utilizadas

01. Backend: Node.js para a estrutura do servidor.
02. Frontend: HTML5, CSS3 (utilizando variáveis para temas dinâmicos) e JavaScript puro.
03. Persistência de Dados: Uso estratégico de localStorage para garantir que nenhuma informação seja perdida ao atualizar a página ou fechar o navegador.

💻 Como Executar o Projeto

01. Certifique-se de ter o Node.js instalado.
02. Clone o repositório: git clone https://github.com/joaquimgomes8/Node_site_cronometros_anotacoes
03. Acesse a pasta do projeto e inicie o servidor: node server.js
04. Abra o navegador em: http://localhost:3000
